## 🧠 SAI: Self-Adaptive Intelligence

> A modular cognitive framework that restructures how AI thinks, reasons and evolves.

```mermaid
flowchart LR
    Q(["💬 User query"]) --> A["🔍 ANALYZE<br/>clarifies intent"]
    A --> P["🧩 PROMPTOR<br/>structures the query"]
    P --> S["🧠 SAI<br/>executes and evolves"]
    S --> G["🕸️ Graph of Reason"]
    S --> F["🔁 Feedback Loop"]
    S --> R["🎭 Role Generation"]
    style Q fill:#161b22,stroke:#FFB347,color:#fff
    style S fill:#3b2a0f,stroke:#FFB347,color:#fff
    style A fill:#161b22,stroke:#a78bfa,color:#fff
    style P fill:#161b22,stroke:#2dd4bf,color:#fff
```

| Capability | What it does |
|---|---|
| `.feedback_loop` | recursive self-improvement |
| `.graph_of_reason` | multi-layer logical analysis |
| `.auto_mpr` | metaphor-driven creative reasoning |
| `.constraint_solver` | turns limits into growth points |
